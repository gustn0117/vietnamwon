# 베트남원

베트남 여행 카테고리 탐색과 1:1 맞춤 상담을 중심으로 만든 반응형 Next.js 웹사이트입니다.

## 실행

```bash
npm install
npm run dev
```

프로덕션 빌드는 아래 명령으로 확인할 수 있습니다.

```bash
npm run build
npm run start
```

## 주요 기능

- 여행 카테고리 검색 및 결과 필터링
- 카테고리별 상세 모달
- 1:1 여행 상담 폼과 완료 상태
- 모바일 내비게이션 드로어
- 데스크톱·태블릿·모바일 반응형 레이아웃
- 로컬 Pretendard 가변 폰트와 최적화된 WebP 이미지

선택한 시각 기준은 `references/option-1.png`, 최종 비교와 브라우저 검수 결과는 `qa/`와 `design-qa.md`에 있습니다.
